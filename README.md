# 🧮 Calculadora JS

Calculadora desenvolvida com **HTML5, CSS3 e JavaScript** como projeto prático de estudos em desenvolvimento web.

O objetivo é praticar lógica de programação, manipulação do DOM e interação com elementos da página, além de aplicar estilos para construir uma interface simples e organizada.

## 🚀 Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — estilização e layout responsivo.
- JavaScript — lógica e interação com os elementos da calculadora.

## ✨ Funcionalidades

- Interface de calculadora.
- Botões para inserir números e operadores.
- Campo de exibição.
- Botões para limpar, apagar e calcular.

## 🎯 Objetivo do projeto

Praticar e consolidar conhecimentos adquiridos durante meus estudos de Análise e Desenvolvimento de Sistemas e programação JavaScript.
